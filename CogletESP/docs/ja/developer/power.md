## 電源装置

CogNog V3.0は、JST-XH入力にシンプルな **5 V / 3 A** の電源をつなぐ設計です。複数ポートの
急速充電器は5 Vで3 Aを出せないことがあり、機器のあいだで電力を配分し直すときに一瞬電源を
切ることがあります。細いUSBケーブルも、負荷がかかると電圧が大きく下がります。書き込み用
USBポートだけで給電した場合、サーボには電源が届きません。

## サーボの段階的な電源オン

9個のサーボを一度にオンにすると、すべてが同時に目標位置へ動き出します。弱い電源では、
この電流のピークで5 Vのラインが下がり、ボードが再起動することがあります。LEDが暗くなり
ながら起動を繰り返すように見えます。

PWM出力を（再び）有効にするたびに（`RP2040/app.py`）、PCA9685の全チャンネルを完全に
オフにしてからnOEを有効にし、重い軸から1つずつサーボをオンにします：

```
YAW → PIT → ROL → LID → MOU → EAL → EAR → EYL → EYR
```

| タイミング | 間隔 | 合計 |
|---|---|---|
| 起動時 | `POWER_UP_GAP_BOOT_MS` = 150 ms | 約1.2秒 |
| 待機からキャリブレーションモードに入るとき | 150 ms | 約1.2秒 |
| 待機から起きるとき（状態、MCPアクション、ダンス） | `POWER_UP_GAP_WAKE_MS` = 60 ms | 約0.5秒 |

この処理はメインループを止めません。終わる前にトルクが解放された場合は中止されます。
おだやかな自分の曲では、LID、EYL、EYRはオフのままです。

ログ：`[POWER] staggered power-up (...)`、`[POWER] all servos on after ... ms`。

## 待機

idleの姿勢が落ち着くと、RP2040は500 ms待ってからnOEをHighにします。サーボのトルクは
すべて解放されます（5 Vのラインはオンのままです）。

Grove Vision AIの推論は、Cogletがidleのとき、キャリブレーションモードのとき、ダンス中は
一時停止し（`AT+BREAK`）、起きると再開します。顔追跡スイッチがオフなら、推論は始まりません。
モジュール自体には電源が入ったままです。ボードにはこれを切るスイッチがありません。

## 再起動の理由

- ESP32-S3：ログの最初の行が `main: Reset reason: ...` です。ブラウンアウトはエラーとして
  記録されます：`Reset reason: BROWN-OUT (supply voltage dropped)`。
- RP2040：`[BOOT] RP2040 reset cause: ...`。RP2040はブラウンアウトを電源投入リセットとして
  報告するので、見分けるにはESPの行を見てください。
