# Cogletの使い方

[ドキュメント](../README.md) · [English](../../en/user/using-coglet.md) · [Deutsch](../../de/user/using-coglet.md) · [Español](../../es/user/using-coglet.md) · **日本語**

## 会話する

**「Hello Coglet」** と言って（またはESP BOOTボタンを押して）、話しかけます。
Cogletが聞いているあいだは赤いLEDが点灯します。Cogletは話す内容や気分に合わせて
頭、耳、目、口を動かし、待機に戻ると目を閉じて力を抜きます。

起動して数秒後、Cogletは一度だけ自分から聞き取りを始めるので、すぐに話しかけられます。

初期設定では、Cogletは話しているあいだは聞いていません。話の途中で割り込みたい場合は、
[設定](settings-and-songs.md)で **話の途中で割り込む** をオンにしてください。

## 頼むと動く

自分の言葉で頼んでください。たとえば：

| こう言うと | Cogletは |
|---|---|
| 「首を振って」 | 首を3回横に振ります |
| 「まばたきして」 | 3回まばたきします |
| 「左耳を動かして」／「右耳を動かして」 | その耳を動かします |
| 「耳を動かして」 | 両耳を動かします |
| 「写真を撮って」／「何が見える？」 | カメラで見ます |

## ダンス

**「踊って」** と言います。Cogletは短く返事をして会話を終え、30秒ほどの曲を流して
踊り、そのあと感想を聞いてきます。

エディションごとに3つのダンスが内蔵されています。名前で頼むことも、Cogletに選ばせる
こともできます：

| エディション | ダンス |
|---|---|
| スタンダード | **mecha**（重厚なエレクトロ）、**evil**（暗いゴシック）、**cat**（やさしい猫ポップ） |
| クリスマス | **lyrical**（きよしこの夜）、**classic**（ジングル・ベル）、**grand**（もろびとこぞりて） |
| エルフ | **workshop**（ひいらぎかざろう）、**mischief**（世の人忘るな）、**party**（おめでとうクリスマス） |
| 雪だるま | **lullaby**（ブラームスの子守歌）、**stomp**（ウェンセスラスはよい王様）、**blizzard**（キャロル・オブ・ザ・ベル） |

自分の曲を追加して、「自分の曲で踊って」や「*曲名* で踊って」と頼むこともできます。
[設定と曲](settings-and-songs.md)を参照してください。

ダンス中に「Hello Coglet」と言うかボタンを押すと、ダンスが止まります。

## リマインダー

たとえば「20分後にパンを出すのを教えて」「明日の8時にアンナに電話するよう教えて」と
頼みます。時間になると、会話をしていないときでも、Cogletがチャイムを鳴らして内容を
話します。「リマインダーは何がある？」「パンのリマインダーを取り消して」と聞くこともできます。

- 最大12件。どれも1回きりです（繰り返しはできません）。
- リマインダーはCogletに保存され、再起動やアップデートのあとも残ります。
- 時刻は、xiaozhi.meがそのCogletに通知するタイムゾーンに従います。

## スイッチとボタン

| 操作部 | はたらき |
|---|---|
| **モード切替スイッチ** ESP / RP2040（書き込み用USB-Cポートの横にある小さな白いスイッチ） | USBポートをどちらのチップにつなぐか。**ESP**（右）のままにしておきます。 |
| **キャリブレーション** スイッチ | 組み立て用に、すべてのサーボをキャリブレーション位置にします。 |
| **サーボテスト** ボタン | キャリブレーションモード中のみ：押しているあいだ、すべてのサーボがキャリブレーション位置を中心に±10°動きます。 |
| **顔追跡**（FACE-TRACK）スイッチ | 顔追跡（目の中のGrove Vision AIカメラ）をオン／オフします。オフにしても、ほかの動きは止まりません。 |
| **ESP BOOT** ボタン | 会話を始める／終える。 |
| **RST** ボタン | ESP32-S3またはRP2040を再起動します。 |

## 電源と待機

待機中、Cogletは目を閉じてサーボの電源を切るので、静かで熱くなりません。起動するときは
電流が急に流れないよう、サーボが1つずつ順番にオンになります。

**5 V / 3 A** の電源を使ってください。動き始めたときにCogletが再起動する場合は、
電源かケーブルの力が足りていません。
