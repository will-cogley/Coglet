# 設定と曲

[ドキュメント](../README.md) · [English](../../en/user/settings-and-songs.md) · [Deutsch](../../de/user/settings-and-songs.md) · [Español](../../es/user/settings-and-songs.md) · **日本語**

どちらも [Coglet Updater](https://will-cogley.github.io/Coglet/) ページで行います。
アップデートと同じようにCogletをつないでください（上側のUSB-Cポート、モード切替スイッチは
**ESP**）。設定と曲はアップデートのたびに残ります。消えるのは **クリーンインストール** の
ときだけです。

## 設定

**Cogletの設定を表示** をクリックし、変えたい項目を変更してから **Cogletに保存** を
クリックします。

| 設定 | 値 |
|---|---|
| ウェイクワード | 英語の単語。例：`hey coglet`、`hello robot`（3〜40文字。スペースも使えます）。はっきり違う2〜3語が最もうまくいきます |
| 起動しきい値 | 1〜50。数字が小さいほど起動しやすくなりますが、誤って起動することも増えます。Cogletがよく聞き逃すなら3、勝手に起動するなら10を試してください |
| 起動音 | Mecha、Evil、Cat、クリスマス、エルフ、雪だるま |
| リマインダー音 | Mecha、Evil、Cat、クリスマス、エルフ、雪だるま |
| 話の途中で割り込む | オン：Cogletは話しながらも聞き続けるので、ウェイクワードなしで割り込めます |

- Cogletが使えないウェイクワード（珍しいつづりなど）の場合は、いつものウェイクワードの
  ままになり、ページがそれを知らせます。
- **話の途中で割り込む** を切り替えると、Cogletが再起動します（20秒ほど）。
  音量50%以下で最もよく動作します。
- **初期値に戻す** を押してから **Cogletに保存** を押すと、すべてファームウェアの初期値に
  戻ります。初期の効果音はエディションごとに異なります。

## 自分の曲

Cogletはあなたの音楽に合わせて踊れます。曲の変換はブラウザーの中で行われ、
インターネットには何もアップロードされません。

1. **マイソング** で音声ファイルか動画ファイルを選ぶか、**曲を追加** にドロップします
   （mp3、wav、m4a、flac、ogg、mp4など）。
2. 曲ごとに名前とダンスのスタイルを確認します：
   - **エネルギッシュ**：ロボット全体が大きく速く動いて踊ります。
   - **おだやか**：耳、頭、台座がゆっくりしたビートでやさしく揺れます。目は休みます。
   - **自動**：ページがどちらかを選びます。
3. **Cogletに保存** をクリックします。
4. 「自分の曲で踊って」または「*曲名* で踊って」と頼みます。

- 1分の曲が8曲ほど入ります。残りの容量はバーで確認できます。曲は60秒で
  フェードアウトして切れます。
- **Coglet内の曲を表示** で保存済みの曲が一覧になり、削除もできます。
- ある曲でダンスがおかしいときは、スタイルを変えて保存し直してください。
- 使用する権利のある音楽だけを使ってください。

曲の追加には、Chrome または Edge のバージョン94以降が必要です。
