# はじめに

[ドキュメント](../README.md) · [English](../../en/user/getting-started.md) · [Deutsch](../../de/user/getting-started.md) · [Español](../../es/user/getting-started.md) · **日本語**

このページでは、組み立て済みのCogletを箱から出して、最初の会話をするまでを説明します。
組み立てについては[組み立て動画](https://youtu.be/EdgYNhH70Qo)と
[NMRobotsナレッジベース](https://nmrobots.com/pages/coglet)を参照してください。

## 必要なもの

- **ChromeまたはEdge** が使えるパソコン（Windows、macOS、Linux）。ほかのブラウザーは
  USBデバイスと通信できません。
- **データ通信対応のUSB-Cケーブル**（充電専用のケーブルもあります）。
- サーボ用の **5 V / 3 A** 電源。複数ポートの急速充電器は5 Vで3 Aを出せないことが
  多いため、シンプルな5 V / 3 Aの充電器がいちばん確実です。
- **2.4 GHz** のWi-Fi（5 GHzのネットワークには対応していません）。

## 1. Coglet UpdaterでCogletをアップデートする

1. <https://will-cogley.github.io/Coglet/> を開きます。
2. Cogletの **上側のUSB-Cポート（書き込み用ポート）** をパソコンにつなぎます。
   小さな白い **モード切替スイッチ** は、出荷時のまま **ESP**（右側）にしておきます。
3. エディション（スタンダード、クリスマス、エルフ、雪だるま。違いは内蔵のダンスと
   効果音だけです）を選び、**接続して更新** をクリックします。
4. ポートのリストからCogletを選び、**完了** と表示されるまで待ちます。

Wi-Fi、ペアリング、リマインダー、設定、曲はそのまま残ります。すべて消えるのは
**詳細オプション → クリーンインストール** を使ったときだけです。

**Cogletの状態を確認** を使うと、何も変更せずに、アップデートが必要かどうかがわかります。

### 古いCogletで必要な追加ステップ

ページに **「あと1ステップ」** と表示されたら、サーボボード（RP2040）に初回セットアップが
必要です。これは2026年11月より前に製造されたCogletだけが対象です：

1. Cogletを外し、モード切替スイッチを左（**RP2040**）にして、つなぎ直します。
2. **サーボボードをセットアップ** をクリックし、リストからRP2040を選びます
   （「Board CDC」や「USB Serial Device」という名前のことが多いです）。
3. **完了** と表示されたらCogletを外し、スイッチを右（**ESP**）に戻してつなぎ、
   **Cogletを確認** をクリックします。

これ以降は、アップデートのたびにCogletが自分でサーボボードも最新に保ちます。

## 2. CogletをWi-Fiにつなぐ

初めての起動時（または自分のネットワークが見つからないとき）、Cogletは自分のWi-Fi
アクセスポイントを開きます：

1. スマートフォンかパソコンで、ネットワーク **Xiaozhi-XXXX** に接続します。
2. 設定ページが開きます。開かない場合は <http://192.168.4.1> にアクセスしてください。
3. 2.4 GHzのネットワークを選び、パスワードを入力して **Connect** を押します。
   iPhoneのインターネット共有を使う場合は **互換性を優先** をオンにします。
4. Cogletが再起動し、ネットワークに接続します。

別のネットワークに切り替えるには、Cogletが起動中でまだ接続していないあいだに
**ESP BOOT** ボタンを押します。前のネットワークを忘れて、アクセスポイントをもう一度開きます。

## 3. Cogletをxiaozhi.meとペアリングする

Cogletはxiaozhi.meのサービスを通して話します。初めて接続すると、**6桁のコード** を言います：

1. <https://xiaozhi.me> にサインインし、コンソールを開きます。
2. デバイスを追加して、コードを入力します。
3. これで準備完了です。**「Hello Coglet」** と話しかけてください。

コンソールでは、声、言語、性格も選べます。

ペアリングは通常のアップデートでは残ります。**クリーンインストール** のあとは、
Cogletが新しいコードを言うので、もう一度ペアリングしてください。

> 自分のパソコンで動くオフラインのバックエンドを開発中です（初期段階）：
> [NMWorkbench](https://github.com/will-cogley/NMWorkbench)。
