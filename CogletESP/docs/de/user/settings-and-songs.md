# Einstellungen und Songs

[Dokumentation](../README.md) · [English](../../en/user/settings-and-songs.md) · **Deutsch** · [Español](../../es/user/settings-and-songs.md) · [日本語](../../ja/user/settings-and-songs.md)

Beides finden Sie auf der Seite [Coglet Updater](https://will-cogley.github.io/Coglet/).
Schließen Sie Coglet wie für ein Update an (oberer USB-C-Anschluss,
Modusschalter auf **ESP**). Einstellungen und Songs bleiben bei jedem Update
erhalten; nur eine **Neuinstallation** löscht sie.

## Einstellungen

Klicken Sie auf **Coglets Einstellungen anzeigen**, ändern Sie, was Sie möchten,
und klicken Sie dann auf **Auf Coglet speichern**.

| Einstellung | Werte |
|---|---|
| Aktivierungswort | Englische Wörter, z. B. `hey coglet` oder `hello robot` (3 bis 40 Buchstaben; Leerzeichen sind erlaubt). Zwei oder drei deutlich verschiedene Wörter funktionieren am besten |
| Aufweckschwelle | 1 bis 50. Niedrigere Zahlen wecken Coglet leichter, aber auch öfter versehentlich. Versuchen Sie 3, wenn Coglet Sie oft überhört, und 10, wenn er von selbst aufwacht |
| Startton | Mecha, Evil, Cat, Weihnachten, Elfen, Schneemann |
| Erinnerungston | Mecha, Evil, Cat, Weihnachten, Elfen, Schneemann |
| Coglet ins Wort fallen | Ein: Coglet hört weiter zu, während er spricht, sodass Sie ihn ohne Aktivierungswort unterbrechen können |

- Kann Coglet ein Aktivierungswort nicht verwenden (ungewöhnliche Schreibweise),
  behält er sein normales Aktivierungswort, und die Seite sagt es Ihnen.
- Das Umschalten von **Coglet ins Wort fallen** startet Coglet neu (etwa 20
  Sekunden). Es funktioniert am besten mit einer Lautstärke von höchstens 50 %.
- **Standardwerte verwenden** und dann **Auf Coglet speichern** setzt alles auf
  die Standardwerte der Firmware zurück. Jede Edition hat eigene Standardtöne.

## Eigene Songs

Coglet kann zu Ihrer Musik tanzen. Die Seite wandelt die Songs in Ihrem Browser
um; nichts wird ins Internet hochgeladen.

1. Wählen Sie unter **Meine Songs** Audio- oder Videodateien aus oder legen Sie
   sie bei **Songs hinzufügen** ab (mp3, wav, m4a, flac, ogg, mp4, …).
2. Prüfen Sie für jeden Song Namen und Tanzstil:
   - **lebhaft**: der ganze Roboter tanzt, mit großen, schnellen Bewegungen;
   - **ruhig**: Ohren, Kopf und Sockel wiegen sanft im langsamen Takt; die Augen ruhen;
   - **Automatisch**: die Seite wählt einen Stil.
3. Klicken Sie auf **Auf Coglet speichern**.
4. Sagen Sie „tanz zu einem meiner Songs“ oder „tanz zu *Songname*“.

- Platz ist für etwa 8 Songs von je einer Minute; der Balken zeigt, wie viel
  frei ist. Songs werden nach 60 Sekunden ausgeblendet.
- **Songs auf Coglet anzeigen** listet die gespeicherten Songs auf, damit Sie
  welche entfernen können.
- Tanzt Coglet zu einem Song seltsam, ändern Sie dessen Stil und speichern Sie
  erneut.
- Verwenden Sie nur Musik, die Sie verwenden dürfen.

Songs brauchen Chrome oder Edge ab Version 94.
