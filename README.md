# Coglet
Will Cogley's DIY Desktop Companion for Makers. See our [knowledge database](https://nmrobots.com/pages/coglet) for this project
# Instructions
*Core documentation for the system and PCB can be found in the [CogNog Datasheet](https://github.com/will-cogley/Coglet/blob/main/CogNogDatasheet.md)*

For a getting-started guide and build instructions, refer to the [build video](https://youtu.be/EdgYNhH70Qo?si=ysY_SmwA_bhApW3r). 

For further reading and troubleshooting, refer to the [knowledge database](https://nmrobots.com/pages/coglet) or the translated docs in this repo.
